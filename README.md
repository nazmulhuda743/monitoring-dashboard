# Monitoring Dashboard — Morning Brief

A desktop CEO morning brief (CDS & YamaMi) built from the approved design in
`design/Bionda_Dashboard.html`. Next.js 16 · React 19 · TypeScript · Tailwind CSS v4.

```bash
npm install
npm run dev        # http://localhost:3000
```

Currently runs on mock data (`src/data/brief.ts`). See `AGENTS.md` for the
architecture, design rules, verification workflow and roadmap.
